Omega Request Traffic

One row per HTTP endpoint, one dot per request in flight. Each dot walks the path its request actually takes — the hops were found by following this.x.y() calls through real method bodies, not guessed from the folder layout. Click any row to open what the request is carrying at each stop.

How to read a row

Every row starts at the entry point and ends wherever that request actually stops. The lanes are ordered the way the architecture is supposed to flow, so a row's silhouette is its conformance.

02

What the tracer can and cannot see

Hops come from resolving this.<prop>.<method>() inside each method body against that class's constructor injections, recursively to a depth of five. That is a real call graph, not an import graph — a class the action injects but never calls does not appear.

Three limits worth stating. Calls made through a local variable rather than this, or dispatched dynamically, are invisible — . Branching is flattened: if a method calls two collaborators, both appear, though a given request might only take one. And recursion past five levels is cut off — the deepest real trace here is levels deep.
