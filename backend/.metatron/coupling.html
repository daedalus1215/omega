Reading it

Both axes are the same list of files, so the matrix is symmetric and the diagonal is each module co-changing with itself. Shade is the Jaccard degree: of all the commits that touched either file, the fraction that touched both. The a→b column in the table below is the asymmetric reading — a file that always drags its partner along is a different story from one that is dragged.
